# Sorun giderme

| Belirti | Çözüm |
|---|---|
| Pages 404 | Yayını bekleyin. Settings → Pages: main ve /(root). Depo kökünde index.html bulunmalı. Site URL'sinde depo adı olmalı. |
| Hedef dosyası eksik/bozuk | assets/targets/sozluk.mind dosyasını paketten tekrar yükleyin. Adı ve küçük/büyük harfleri koruyun. Boyut: 840.601 bayt. |
| Kütüphane indirilemedi | İnternet veya CDN engeli olabilir. Başka ağda deneyin, engelleyicileri kontrol edin, sayfayı yenileyin. |
| Kamera açılamadı | HTTPS adresini Chrome'da açın. Site ayarlarından ve Android'in Chrome uygulama izinlerinden kameraya izin verin. Diğer kamera uygulamalarını kapatın. |
| Hazırlık zaman aşımı | İzni kontrol edip sayfayı yenileyin. Başlatma düğmesi yenilenene kadar kapalı kalır. |
| Siyah görüntü | Lensi, kamera iznini ve diğer uygulamaları kontrol edin. Chrome'u güncelleyip sayfayı yenileyin. |
| Görsel tanınmıyor | PDF'deki özgün hedefin tamamını gösterin. Rastgele fotoğraf çalışmaz. Parlamayı azaltın; mesafeyi ve açıyı yavaşça ayarlayın. |
| Yanlış kelime/model | Değiştirilen hedefler varsa sıra Elma 0, Ağaç 1 olmalı. Hazır dosya bu sırayla test edildi. |
| Kelime var, model yok | Kamerasız önizlemeyi açın. assets/models/elma.glb ve agac.glb dosyalarını kontrol edin. |
| Sekme değişince kamera kapandı | Beklenen davranış. Geri dönünce yeniden başlatın. |
| Görüntü takılıyor | Diğer sekmeleri kapatın, telefonu soğutun, ışığı artırın. A52 performansını test kaydına yazın. |

Güncelleme sonrası eski sürüm görünüyorsa yeniden yükleyin; gerekirse bu sitenin önbelleğini temizleyin. Hata devam ederse tam mesajı, cihaz/Android/Chrome sürümünü ve koşulları kaydedin.
